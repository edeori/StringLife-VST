# StringLife UI mockup

Open `stringlife-ui.html` directly in a browser. `stringlife-ui.png` is the
checked reference render. The concept places String Age
at the centre, retains Guitar/Bass and Normal/Delta choices, exposes Spark,
Bite, Shimmer and Bloom as a consistent macro row, and uses the common Moth
header, bypass, A/B, panels, knobs and range behaviour.

`Assets/stringlife-background.png` bakes the String Age, I/O and four macro
wells into the shell; the matching HTML elements are transparent containers.
